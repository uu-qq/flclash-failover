# FlClash 故障转移脚本 — 节点挂了自动换，不用手动切

给 FlClash（翻墙代理软件）用的小脚本。

**解决什么问题**：机场节点经常某个地区的突然全连不上，你得手动一个个试。
装上这个脚本后，它会把你的节点按地区分好队，**哪个地区全挂了就自动切到下一个地区**，
恢复了还会自己切回来。你只管用，不用再盯着节点列表。

## 它会做的事

- 按节点名字认出地区，分成四队：**新加坡 / 日本 / 香港 / 美国**（名字是中文、英文、国旗 emoji 都能认）
- 每队内部每分钟测一次速，自动用最快的那个活节点
- 四队的优先顺序是 **新加坡 → 日本 → 香港 → 美国**：新加坡全挂了自动用日本，以此类推
- 某个地区一个节点都没有的，自动跳过，不会报错
- 你原来的分组和规则一点都不动，只是多出一个叫 **「故障转移」** 的选项

## 怎么装（五步）

1. 打开 FlClash →「配置」，点中你的订阅
2. 进「扩展」→ 切到 **脚本模式**（注意，必须是脚本模式，原因见下面常见问题）
3. 把 [`failover-script.js`](failover-script.js) 文件里的全部内容粘贴进去，保存
4. 点「立即应用」
5. 回到代理页面，在节点选择里选 **「故障转移」**，完事

## 常见问题

**为什么必须用脚本模式？用“标准模式”贴不行吗？**
不行。标准模式只能改“流量走哪条路”的规则，加不了新的分组；
这个脚本要新建分组，只能走脚本模式。把别的文件（比如 YAML 配置）贴进脚本模式，
会直接报错（提示第一行字符不对），贴错了一眼就能认出来。

**选了「故障转移」之后，还要自己选节点吗？**
不用。它自己测速、自己切换，你永远只选「故障转移」这一个就行。

**想改地区顺序可以吗？**
可以。改脚本里的 `regions` 那几行就是改顺序和增减地区；
测速间隔是每个组里的 `interval: 60`（秒）。

## 说明

自用脚本，配合 FlClash（mihomo 内核）使用。在 Kitty Network 订阅上实测可用；
其他订阅只要节点名字里带地区信息（中英文、国旗都行），一般都能直接套用。
