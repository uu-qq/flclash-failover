# FlClash 故障转移脚本

给 FlClash 的订阅配置自动加上「故障转移」策略组：某个地区节点全超时，自动切到下一个地区，不用手动换节点。

## 它做了什么

- 按节点名把节点分到四个地区组：**新加坡 / 日本 / 香港 / 美国**（中英文名、国旗 emoji 都能认）
- 每个地区组是 `url-test` 类型：每 60 秒做一次健康检查，自动用组里最快的活节点
- 顶层是一个 `fallback` 组「故障转移」，顺序是 **新加坡 → 日本 → 香港 → 美国**：当前地区全部超时就自动切下一个，恢复后自动切回
- 某个地区一个节点都没有时，自动跳过该组，不会报错
- 不改动原配置的分组和规则，只是把新组加进去，并把「故障转移」插到节点选择的最前面

## 使用方法

1. 打开 FlClash → 配置 → 选中你的订阅
2. 进入「扩展」→ 切到 **脚本模式**
3. 把 [`failover-script.js`](failover-script.js) 的全部内容粘贴进去，保存
4. 点「立即应用」
5. 回到代理页，在节点选择里选 **「故障转移」**，完事

> 注意：必须用脚本模式。扩展的「标准模式」只能追加分流规则，加不了策略组（YAML 覆写在那里不生效）。

## 自定义

想改地区顺序或增减地区，改脚本里的 `regions` 数组即可——每行是 `[组名, 匹配节点名的正则]`。健康检查间隔是组里的 `interval: 60`（秒），检查地址是 `http://www.gstatic.com/generate_204`。

## 说明

自用脚本，配合 FlClash（mihomo 内核）使用。在 Kitty Network 订阅上实测可用，其他订阅只要节点名带地区信息一般都能直接套用。
